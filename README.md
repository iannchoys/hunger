# Hungry People

## Что реализовано

### Пользовательская часть

- адаптивная главная страница ресторана;
- фиксированная шапка сайта;
- плавная прокрутка по разделам страницы;
- регистрация пользователя;
- вход и выход из аккаунта;
- восстановление пароля через email;
- бронирование столика;
- контактная форма;
- фильтрация блюд по категориям;
- слайдер Specialities;
- галерея изображений;
- Яндекс Карта;
- подвал сайта.

### Серверная часть

- проект реализован на Django;
- используется база данных SQLite;
- данные сохраняются в базе данных;
- формы обрабатываются без перезагрузки страницы через AJAX;
- реализована серверная проверка данных;
- пользователи хранятся в базе данных;
- пароли хранятся в зашифрованном виде;
- бронирования сохраняются в базе данных;
- контактные сообщения сохраняются в базе данных;
- восстановление пароля работает через уникальный токен;
- письма отправляются через SMTP;
- контентом можно управлять через Django Admin.

## Технологии

## Как запустить проект

### Команды ниже рассчитаны на Git Bash в Windows.

- cd ~/Downloads/hunger-main/hunger-main
- python -m venv .venv
- source .venv/Scripts/activate
- pip install -r requirements.txt
- cp .env.example .env
- notepad .env

### Вписать настоящие SMTP-настройки своей почты

- python manage.py migrate
- python manage.py loaddata restaurant/fixtures/initial_data.json
- python manage.py check
- python manage.py createsuperuser
- python manage.py runserver

## На сайте можно:

- просмотреть информацию о ресторане;
- посмотреть меню;
- отфильтровать блюда по категориям;
- зарегистрироваться;
- войти в аккаунт;
- выйти из аккаунта;
- восстановить пароль через email;
- забронировать столик;
- отправить сообщение через контактную форму;
- открыть административную панель.


## Административная панель

http://127.0.0.1:8000/admin/

Через Django Admin можно управлять:

- пользователями;
- бронированиями;
- контактными сообщениями;
- блюдами меню;
- блоками About и Team;
- разделом Specialities;
- событиями Private Events;
- запросами восстановления пароля.
